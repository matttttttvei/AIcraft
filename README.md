Полноценная, рабочая воксельная 3D-песочница в духе классических ранних версий Minecraft, работающая в браузере на чистом WebGL и JavaScript без тяжелых движков, компиляторов и внешних npm-библиотек.

---

## 🚀 Быстрый запуск

### Способ 1. Напрямую в браузере (без установки)
Дважды кликните по `index.html` или перетащите его в окно любого современного браузера (Chrome, Edge, Firefox, Safari).

### Способ 2. Через локальный сервер (Node.js)
```bash
# Запуск встроенного веб-сервера (порт 3000)
node server.js
```
или:
```bash
npm start
```
Затем откройте в браузере: **`http://localhost:3000`**

## 🧩 Особенности и архитектура

1. **Воксельный рендеринг (WebGL):**
   - Собственный рендерер без библиотек Three.js или Babylon.js.
   - Оптимизированный **Face Culling**: генерируются только видимые наружные грани блоков, соприкасающиеся с воздухом.
   - Освещение по граням (Ambient + Directional shading) и атмосферный туман глубины.
   - Поэтапная анимация разрушения блоков (трещины от стадии 0 до 9 с наложением декалей разрушения).

2. **Процедурная генерация мира:**
   - 3D воксельная сетка `48 × 32 × 48` блоков.
   - Неровный реалистичный рельеф (холмы, равнины, углубления).
   - Слоистая геология: неразрушимый нижний слой коренной породы (бедрока), слои камня и руд (угольная, железная, золотая, алмазная, редстоун), земля и поверхностная трава.
   - Процедурные деревья с листвой и стволами из бревен.

3. **Интеллектуальный ИИ Свиньи (Continuous A* Pathfinding AI):**
   - **Непрерывная ходьба без остановок:** свинья выбирает случайные точки на траве на расстоянии 10–20 блоков и движется по рассчитанному пути. При достижении цели в тот же кадр бесшовно подхватывается следующий маршрут.
   - **Предварительный расчёт пути:** пока свинья идёт к текущей цели, следующий путь уже строится в фоновом режиме через глобальную очередь (не более 1 поиска A* за кадр).
   - **Полноценный A* по 3D-рельефу:** учитывает подъёмы и спуски на 1 блок, авто-прыжки на ступеньки, 2 блока запаса высоты для прохода, обход стен и обрывов.
   - **Защита от «целования углов»:** диагональные шаги разрешены только если свободны обе соседние клетки + штраф за движение вплотную к стене (`WALL_PENALTY`).
   - **Идеальная кинематика:** свинья идёт строго головой и пятачком вперёд (исправлен поворот модели, исключена ходьба боком/задом).
   - **Чистый визуал:** никаких отладочных линий, столбов или плашек в игровом процессе.
   - **Интерактивность:** реакция на урон (визг, отскок, побег в панике с покраснением), периодическое хрюканье и возможность погладить свинку.

4. **Анимация разрушения блоков:**
   - Послойное наложение текстур трещин `destroy_stage_0.png` — `destroy_stage_9.png` из папки `destroy/`.
   - Защита неразрушаемых блоков (бедрок).

5. **Звуковой движок (Web Audio API):**
   - Процедурные звуковые эффекты шагов, ломания, установки и хрюканья свиньи без необходимости скачивания внешних тяжелых MP3/WAV.

6. **Сохранение и экспорт мира:**
   - Сохранение и мгновенная загрузка в LocalStorage браузера.
   - Экспорт и импорт карты мира в компактные JSON-файлы.

## 📁 Структура проекта

```text
├── index.html          # Главная HTML-страница, разметка HUD и оверлеев
├── style.css           # Стили интерфейса, прицела, хотбара и индикаторов
├── server.js           # Локальный статический веб-сервер Node.js (без зависимостей)
├── package.json        # Манифест проекта
├── README.md           # Документация и руководство
├── DISCLAIMER.md       # Юридическое уведомление о фан-версии (не продукт Mojang)
├── LICENSE             # Лицензия MIT
├── .gitignore          # Исключения для Git
├── destroy/            # Спрайты стадий разрушения блока (0-9)
├── assets/             # Текстуры блоков, сущностей, предметов и моделей
└── js/
    ├── math.js         # 3D-математика, матрицы MVP, кватернионы/углы
    ├── asset_data.js   # Встроенные текстуры в Base64 для офлайн-запуска
    ├── textures.js     # Атлас текстур, генерация процедурных fallback-текстур
    ├── world.js        # Воксельная сетка, генерация ландшафта, руд, бедрока
    ├── raycast.js      # Алгоритм DDA (Amanatides-Woo) для прицеливания
    ├── player.js       # Физика игрока, гравитация, AABB-коллизии
    ├── audio.js        # Процедурный синтез звуков на Web Audio API
    ├── storage.js      # Сериализация и сохранение мира в LocalStorage / JSON
    ├── renderer.js     # Шейдеры WebGL, рендер чанков, туман, сетка блока
    ├── pig.js          # Непрерывный ИИ свиньи (A* с очередью, предрасчёт пути, отладка)
    └── main.js         # Главный игровой цикл, обработка ввода, логика UI
```
